# AI Call Guard Boot Companion

This optional KernelSU/Magisk module starts `com.codex.aicallguard` after boot and nudges its foreground service every five minutes.

It does not overlay system APKs or modify system files. Install the release APK, enable the rule engine once, then install `ai_call_guard_boot.zip` from the root manager.

To remove it, disable or uninstall the module from KernelSU/Magisk.
